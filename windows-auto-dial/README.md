# 广工校园网 / PPPoE 开机自动拨号

Windows 登录后自动帮你把宽带（PPPoE）拨上，不用再打开「设置 → 网络 → 拨号 → 连接」。

适用于：校园网客户端、运营商 PPPoE 宽带，以及任何在 Windows 拨号列表里出现的连接。

## 快速开始

```powershell
git clone https://github.com/<你的用户名>/gdut_net_auto.git
cd gdut_net_auto\windows-auto-dial
.\install.ps1
```

然后**确认三件事**：

1. 打开脚本，把开头的 `CONN` 改成你自己的拨号连接名
   （不确定的话，在命令行运行 `rasdial`，或者看「设置 → 网络 → 拨号」里的名字）。
2. **把账号密码填进脚本的 `USERNAME` / `PASSWORD`** —— Windows 11 存不住 PPPoE 密码，不填会一直报 628，详见下面「踩坑」。
3. 网线插好：PPPoE 走有线网卡，Wi-Fi / 手机热点替代不了。

之后每次登录 Windows，等几秒就会自动连上。全程无窗口。

> **前提：网口必须有物理链路。** PPPoE 走的是有线网卡，手机热点 / Wi-Fi 无法代替。
> 没插网线时脚本只会报 `619` / `651` 并退避重试，不会影响你当前的 Wi-Fi 上网。

## 踩坑：Windows 11 存不住 PPPoE 密码

这是本项目踩过最久的坑，先看症状：

| 现象 | 说明 |
|---|---|
| 在「设置 → 网络 → 拨号」里手动点连接 **能成功** | 密码是你当场手打的 |
| 命令行 `rasdial 你的连接名` **一直是 628** | 它拿的是系统里"保存的"凭据，而那份是空的 |
| `rasphone.pbk` 里搜不到 `Password=` 键 | 密码根本没落盘 |
| 凭据管理器里没有任何 RAS/拨号条目 | 同上 |

原因：Windows 11 里新建的 PPPoE 拨号条目，「记住登录信息」这个勾**不会真正写入电话簿**，所以任何非交互的拨号（`rasdial`、脚本、计划任务）都会在"正在验证用户名及密码"这一步被服务器掐断，返回 628 而不是 691。

### 处理办法

**推荐：把账号密码写进脚本**（本项目默认做法）

```vbs
Const USERNAME   = "你的账号"
Const PASSWORD   = "你的密码"
```

`rasdial` 会显式带上它们，不再依赖系统存储。

**备选：用经典拨号窗口保存**

`Win+R` → `rasphone -d 你的连接名` → 勾选「为下面用户保存用户名和密码」。部分系统版本有效，可以先用下面的命令确认有没有写进去：

```powershell
Select-String "$env:APPDATA\Microsoft\Network\Connections\Pbk\rasphone.pbk" -Pattern '^Password='
```

有输出才算保存成功。

### 安全性说明

密码以**明文**存在 `%LOCALAPPDATA%\AutoDial\AutoDial.vbs`，只有当前用户和管理员可读。仓库里的脚本始终保持空白凭据，`install.ps1` 升级时会自动沿用你本机已填好的值，**不会把密码带到 git 里**。

## 工作方式

- 脚本装在 `%LOCALAPPDATA%\AutoDial\`，「启动」文件夹里只放一个指向它的 `.lnk` 快捷方式。
  Windows 11 已弃用 VBScript，**裸 `.vbs` 直接丢进启动文件夹不会被系统执行**，必须用快捷方式。
- 先等 8 秒让网卡就绪，然后用 `rasdial <连接名>` 拨号。
- 已经连上就直接退出，不会重复拨号、不会打断现有连接。
- 失败自动重试：普通失败等 15 秒，端口不可用（没插网线、网卡没就绪）等 60 秒，最多 40 次。
- 同一时间只允许一份脚本运行（心跳锁 `%TEMP%\autodial.lock`），避免两份互抢拨号端口。
- 账号密码完全交给 Windows 保管（凭据用 DPAPI 加密），脚本里不出现明文。

## 文件说明

| 文件 | 作用 |
|---|---|
| `AutoDial.vbs` | 主脚本，顶部常量可改连接名、重试次数、等待时间 |
| `install.ps1` | 复制脚本到 `%LOCALAPPDATA%\AutoDial`，并在「启动」文件夹建快捷方式 |
| `uninstall.ps1` | 删除快捷方式和脚本目录 |

## 可调参数

| 常量 | 默认 | 说明 |
|---|---|---|
| `CONN` | `你的连接名` | 拨号连接名，改成自己电脑上的名字 |
| `USERNAME` / `PASSWORD` | 空 | 留空 = 用 Windows 保存的凭据；填了则强制使用（会以明文存在脚本里） |
| `MAXTRY` | 40 | 最多尝试次数 |
| `WAITSEC` | 15 | 普通失败后等待秒数 |
| `NOLINKWAIT` | 60 | 端口不可用（没插网线等）时等待秒数 |
| `STARTDELAY` | 8 | 登录后先等几秒 |
| `LOCKSTALE` | 120 | 锁文件超过多少秒视为失效（防止异常退出后永久锁死） |

## 排查

日志在 `%TEMP%\autodial.log`，每次运行都会追加记录。

| 退出码 | 含义 | 处理 |
|---|---|---|
| `0` | 成功 | — |
| `691` | 用户名/密码错误或没有保存 | 手动拨号一次并勾选「记住密码」 |
| `623` | 找不到该拨号连接 | 检查 `CONN` 是否和 `rasdial` 列出的名字一致 |
| `619` | 端口不可用 | 常见于**网线没插**、网卡没就绪；接回网线后会自动接上 |
| `651` | 拨号设备报错 | 同上，或上一次拨号的残留；重启连接即可 |
| `756` | 已有另一个拨号在进行 | 同时跑了两份脚本。新版有单实例锁，旧版没有，升级即可 |
| `797` | 拨号设备（网卡/调制解调器）没就绪 | 网线没插好，或网卡驱动异常 |
| `628` | 服务器在完成连接前终止（认证阶段被踢） | 链路是通的，属于账号侧问题：账号在别处在线、被临时锁定、或密码不对 |

脚本遇到 691/623 时会自动弹出拨号窗口，方便你手动连一次。

## 取消

```powershell
.\uninstall.ps1
```

或直接在「任务管理器 → 启动应用」里禁用 `AutoDial.vbs`。

## 限制

- 只在**登录后**拨号，不处理"未登录就拨号"（那需要建计划任务并以 SYSTEM 运行，还要额外存凭据）。
- 必须有线连接：网线插在网口上（或交换机 / 路由器 LAN 口）。Wi-Fi、手机热点无法承载 PPPoE 拨号。
- 连接中途掉线不会自动重连（Windows 自己的"断线重拨"选项会处理一部分情况）。
- 换宽带密码后需要同步修改脚本里的 `PASSWORD`（Windows 那边存不住）。
