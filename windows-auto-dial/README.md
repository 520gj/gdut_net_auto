# 广工校园网 / PPPoE 开机自动拨号

Windows 登录后自动帮你把宽带（PPPoE）拨上，不用再打开「设置 → 网络 → 拨号 → 连接」。

适用于：校园网客户端、运营商 PPPoE 宽带，以及任何在 Windows 拨号列表里出现的连接。

## 快速开始

```powershell
git clone https://github.com/<你的用户名>/gdut_net_auto.git
cd gdut_net_auto\windows-auto-dial
.\install.ps1
```

然后**确认两件事**：

1. 打开 `AutoDial.vbs`，把开头的 `CONN` 改成你自己的拨号连接名
   （不确定的话，在命令行运行 `rasdial`，或者看「设置 → 网络 → 拨号」里的名字）。
2. 拨号密码必须已被 Windows 记住：手动连接一次，勾选「为下面用户保存用户名和密码」。

之后每次登录 Windows，等几秒就会自动连上。全程无窗口。

## 工作方式

- 放在当前用户的「启动」文件夹（`Win+R` → `shell:startup`），登录后由 `wscript.exe` 隐藏执行。
- 先等 8 秒让网卡就绪，然后用 `rasdial <连接名>` 拨号。
- 已经连上就直接退出，不会重复拨号、不会打断现有连接。
- 失败（网线未插、认证服务器没响应）就每 15 秒重试，最多 40 次，大约覆盖 10 分钟。
- 账号密码完全交给 Windows 保管（凭据用 DPAPI 加密），脚本里不出现明文。

## 文件说明

| 文件 | 作用 |
|---|---|
| `AutoDial.vbs` | 主脚本，顶部常量可改连接名、重试次数、等待时间 |
| `install.ps1` | 复制到「启动」文件夹 |
| `uninstall.ps1` | 从「启动」文件夹删除 |

## 可调参数

| 常量 | 默认 | 说明 |
|---|---|---|
| `CONN` | `kdlink` | 拨号连接名 |
| `USERNAME` / `PASSWORD` | 空 | 留空 = 用 Windows 保存的凭据；填了则强制使用（会以明文存在脚本里） |
| `MAXTRY` | 40 | 最多尝试次数 |
| `WAITSEC` | 15 | 每次失败后等待秒数 |
| `STARTDELAY` | 8 | 登录后先等几秒 |

## 排查

日志在 `%TEMP%\autodial.log`，每次运行都会追加记录。

| 退出码 | 含义 | 处理 |
|---|---|---|
| `0` | 成功 | — |
| `691` | 用户名/密码错误或没有保存 | 手动拨号一次并勾选「记住密码」 |
| `623` | 找不到该拨号连接 | 检查 `CONN` 是否和 `rasdial` 列出的名字一致 |
| `797` | 拨号设备（网卡/调制解调器）没就绪 | 网线没插好，或网卡驱动异常 |
| `628` | 端口被挂断 | 刚断开就立刻重拨时的竞争，重试即可自愈 |

脚本遇到 691/623 时会自动弹出拨号窗口，方便你手动连一次。

## 取消

```powershell
.\uninstall.ps1
```

或直接在「任务管理器 → 启动应用」里禁用 `AutoDial.vbs`。

## 限制

- 只在**登录后**拨号，不处理"未登录就拨号"（那需要建计划任务并以 SYSTEM 运行，还要额外存凭据）。
- 连接中途掉线不会自动重连（Windows 自己的"断线重拨"选项会处理一部分情况）。
- 换宽带密码后需要重新勾选一次「记住密码」。
